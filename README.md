# Arsenal Vandal (RASCUNHO)

Mashup solo: ELDEN RING NIGHTREIGN (jogo principal) + VALORANT (companion).
Você joga NIGHTREIGN com armas, sons e HUD do VALORANT no lugar dos efeitos originais.

STATUS: somente design. Nenhum código foi escrito, nada foi testado, nada foi publicado.

- Título: Arsenal Vandal

## Regras
- NIGHTREIGN = role "primary"; VALORANT = role "companion" (Melty passa a pasta via {game:valorant}).
- Nada do VALORANT é copiado: o mod lê os arquivos da cópia instalada do jogador.
- VALORANT nunca é iniciado com mod (sem exposição a anti-cheat).
