# Continuar a construção
1. Abra o Claude Code (ou Codex) no seu PC, nesta pasta.
2. Cole o prompt original de publicação do Melty (com um token novo: revogue o antigo no Melty Studio > Coding agents).
3. Diga: "O design já está em design/sheets.json; construa o Arsenal Vandal solo."
4. Ele deve: achar as pastas dos jogos, escolher a rota de mod, preencher as planilhas, construir, testar com test_release, e só então perguntar se você quer publicar.
